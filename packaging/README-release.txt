osu!mania 合谱工具 v1.7
========================

【重要】
本版本是自包含 .NET 8 程序：exe 自带运行时，
不需要安装 .NET Framework，也不需要装 .NET SDK。
系统要求：Windows 10 / 11 64 位。

【v1.7 修复】
- 渐入改为二次曲线（qua），从接近静音缓慢升起，不再像线性淡入那么直。
- 修正 OD 标签被截成 O 的问题。
- 输出文件名输入框缩短，合并按钮不会被挤住或遮挡。`r`n- 长前奏现在会真正渐入（之前只裁到 5 秒，没有淡入）。
- 尾奏渐出已实测确认。
- 音频比最后一个 note 短时，会自动补静音到该 note，
  不会再出现两首歌之间 20 多秒的空白。
【用途】
把多张 osu!mania 谱面（.osu）首尾拼接成一张谱：
上一张最后一个 note 的结束时间（长条 LN 按"面尾"算），
到下一张第一个 note 的开始时间，间隔正好 10 秒（可在界面里改）。

四首歌不一样也没关系：工具会处理音频、统一流速，
最后输出一个可以直接导入 osu! 的 .osz。

【快速开始】
1. 把整个文件夹解压到本地（例如 C:\OsuManiaMerger\）
2. 双击 OsuManiaMerger.exe
   如果打不开，先双击 Start.bat（会自动解除文件锁定）
3. 把 .osu 按想要的顺序拖进窗口（或点"添加谱面"）
4. 间隔保持 10.00 秒
5. 填写 Title / Artist / Difficulty / Creator / 音频文件名
   按需调 OD / HP
6. 输出文件夹默认是 output，文件名默认是 Artist - Title，可按需修改
7. 点"开始合并"

输出：<文件名>.osz（压缩包里就是 .osu + .mp3）
直接拖进 osu! 窗口，或放进 osu!\Songs\ 下按 F5 刷新。

【默认输出】
- 程序旁边有一个 output 文件夹，默认所有 .osz 都输出到这里。
- 默认输出文件名是 Artist - Title，
  例如 Various Artists - Malody 4K Extra Dan v4。
- 如果你手动改过输出文件名，之后再改 Title / Artist 不会覆盖你的自定义名。
【音频规则（不硬切）】
- 每首歌的前奏、尾奏各最多保留 5 秒。
- 前奏/尾奏本身不超过 5 秒：完整保留，不做淡化。
- 前奏/尾奏超过 5 秒：只保留靠近 note 的 5 秒，
  并做 5 秒渐入（前奏）或 5 秒渐弱（尾奏）。
- 第一首歌保留完整前奏（它前面没有别的歌）。
- 两段音频不会重叠；10 秒间隔里剩下的部分用静音补齐。
- 因此 note 与 note 之间仍然精确 10 秒，但衔接处不再是"啪"一下断掉。

【流速修正（SV，全局）】
- 删除原谱所有绿线（继承时间点）。
- 音频拼好之后，统计整首谱里每种 BPM 实际持续的总时间，
  取累计时间最长的那个 BPM 作为【全局基准 BPM】。
- 保留全部红线（BPM 点），并在每条红线处生成一条绿线：
      SV = 全局基准 BPM / 当前 BPM
  例：全局基准 200，当前 250 → SV 0.80（减速）；
      当前 100 → SV 2.00（加速）；
      基准 BPM 自己 → SV 1.00。
- 所有歌共用同一个基准，所以整首合谱的视觉流速是统一的。

【OD / HP】
「谱面信息」右下角的 OD / HP 可以直接调（0~10，步进 0.1），
会写入 .osu 的 OverallDifficulty / HPDrainRate。
第一次添加谱面时会自动读取第一张谱面的值，之后可以手动改。

【语言 / Language】
「拼接」栏右侧的 Language 可以切换 中文 / English。
切换后程序会自动重启，界面、日志、弹窗和预设名都会跟着变。
语言设置保存在 %APPDATA%\OsuManiaMerger\settings.txt。

【谱面信息预设】
界面"预设"下拉可以快速填入谱面信息：
- 从第一张谱面读取：读取第一张的 Title / Artist / Creator / Difficulty。
- 合谱默认值：恢复默认值。
- 上次使用：自动记住上一次合并时用的信息（下次启动自动填入）。
- 保存：把当前填写的信息存成自定义预设。
预设保存在 %APPDATA%\OsuManiaMerger\presets.txt。

【写入 .osu 的信息】
Title / Artist / Creator / Difficulty 都会写进谱面；
"音频文件名"决定 mp3 的文件名和 .osu 里的 AudioFilename。
输出会重置 AudioLeadIn、PreviewTime，并移除背景图和故事板引用。

【先试一下】
"samples"文件夹里有 4 张 4K 示例谱和对应 mp3。
按 1→2→3→4 拖进工具，直接点合并就能看到完整效果。

【限制 / 注意事项】
- 所有谱面的键数必须一致（例如都是 4K）。本工具按原轨道拼接，不做 4K/7K 转换。
- .osu 里写的音频文件必须和 .osu 在同一个文件夹（相对路径）。
- 原谱 AudioLeadIn 不是 0 的，可能有几十毫秒偏差（绝大多数谱是 0）。
- 自定义音效（hitsound）文件不会被打包，osu! 会退回默认音效。
- 原谱的绿线会被全部替换；如果原谱用绿线做过特殊演出（kiai 等），会被一并清掉。

【如果打不开 / 还是提示 This application could not be started】
1. 先双击 Start.bat（会自动解除文件锁定再启动）。
2. 把整个文件夹放到 C:\OsuManiaMerger\ 这类本地路径再试，
   不要放在 OneDrive、网络盘，也不要直接在压缩包里双击。
3. 确认 OsuManiaMerger.exe 大小约 68 MB；如果明显不对，重新解压。
4. 把整个文件夹加入杀毒软件白名单，防止 exe 被截断或隔离。
5. 仍然不行，把 winver 截图和报错截图发我。

【ffmpeg】
拼接音频依赖 ffmpeg.exe，已经放在程序旁边，正常不需要管。
如果被杀毒软件删掉，把 ffmpeg.exe 放回程序目录即可；
也可以点界面上的"选择 ffmpeg..."指定别的位置。
（ffmpeg 来自 https://www.gyan.dev/ffmpeg/builds/，GPL 许可，
  源码见 https://ffmpeg.org/）

【卸载】
整个文件夹删掉即可，不写注册表、不装服务。
